TASC compiler sources

Microsoft TASC 2.01. TASC runs as three Applesoft programs compiled by TASC itself, sharing a COMMON block: PASS0 asks the questions and sets up, PASS1 compiles, PASS2 finishes the object file. RUNTIME is the machine language library compiled programs call; MAKE RUNTIME builds it.

Disk images

140K DOS 3.3 disk images (16 sectors, DOS order) for an Apple II or an emulator. To compile a pass, boot the TASC disk with the source disk in drive 2 and answer PASS1,D2 at the source file question and PASS1.OBJ,D1 at the object file question (the source disk has no room for object files).

AASCAD

aascad.py (253,925 bytes, sha256 167812fe52f76912…)

Another AppleSoft Compiler And Decompiler: one Python script (3.9 or later, nothing to install) that compiles an Applesoft program exactly as TASC 2.01 does, byte for byte, and turns a TASC object file back into an Applesoft program, checking that it compiles to the same bytes. Its options and how to use it; project page on GitHub. AASCAD is copyright © 2026 Lydian Scale Software, with portions by Microsoft.

python3 aascad.py compile BALL.txt -o BALL.OBJ
python3 aascad.py decompile BALL.OBJ -o BALL.txt --bas BALL.bas
python3 aascad.py compile "TASC.dsk::BALL" -o "WORK.dsk::BALL.OBJ"
python3 aascad.py --help
