TASC compiler sources

Microsoft TASC 2.01. TASC runs as three Applesoft programs compiled by TASC itself, sharing a COMMON block: PASS0 asks the questions and sets up, PASS1 compiles, PASS2 finishes the object file. RUNTIME is the machine language library compiled programs call; MAKE RUNTIME builds it.

ProgramWhat it does
PASS0Pass 0: dialog, DOS patches, tables, then runs pass 1overviewlisting
PASS1Pass 1: parsing, symbol table and code generationoverviewlisting
PASS2Pass 2: constants, variable routines, backpatching, header and reportoverviewlisting
MAKE RUNTIMEBuilds the RUNTIME library file from DATA statementsoverviewlisting
