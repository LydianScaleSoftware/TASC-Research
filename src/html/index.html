TASC compiler sources

Microsoft TASC 2.01. TASC runs as three Applesoft programs compiled by TASC itself, sharing a COMMON block: PASS0 asks the questions and sets up, PASS1 compiles, PASS2 finishes the object file. RUNTIME is the machine language library compiled programs call; MAKE RUNTIME builds it.

Disk images

140K DOS 3.3 disk images (16 sectors, DOS order) for an Apple II or an emulator. To compile a pass, boot the TASC disk with the source disk in drive 2 and answer PASS1,D2 at the source file question and PASS1.OBJ,D1 at the object file question (the source disk has no room for object files).

TASCAD

tascad.py (253,151 bytes, sha256 41e47676117dd46f…)

The AppleSoft Compiler and Decompiler: one Python script (3.9 or later, nothing to install) that compiles an Applesoft program exactly as TASC 2.01 does, byte for byte, and turns a TASC object file back into an Applesoft program, checking that it compiles to the same bytes. It takes a text listing or a tokenized program, TASC’s options as flags (--no-int-arith, --no-int-const, --resume, --library, --program, --variables), and finds a decompiled object’s options by itself. A file inside a disk image is named IMAGE::NAME; disk images are read and written with CiderPress II’s command-line program (--cp2 PATH or the CP2PATH environment variable).

python3 tascad.py compile BALL.txt -o BALL.OBJ
python3 tascad.py decompile BALL.OBJ -o BALL.txt --bas BALL.bas
python3 tascad.py compile "TASC.dsk::BALL" -o "WORK.dsk::BALL.OBJ"
python3 tascad.py --help
