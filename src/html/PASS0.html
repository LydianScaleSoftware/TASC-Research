10REM ! INTEGER MN,EL,SC

INTEGER VARIABLES

EL IS LIBRARY ROUTINE ($0947) THAT RESETS THE STACK, DROPPING EVERY PENDING GOSUB AND FOR, AND RESETS THE DATA POINTER; CALLED AFTER AN ERROR

MN IS DRIVE MOTOR-OFF SWITCH FOR THE BOOT SLOT

SC IS 1 IF THE SOURCE AND OBJECT FILES ARE ON THE BOOT DRIVE (MOTOR KEPT ON), ELSE 0

SC() IS SYMBOL TABLE: CHAIN HEADS, THEN ENTRIES LINKED THROUGH THEIR FIRST WORD

20REM ! INTEGER P8,N1,OO,O4

INTEGER VARIABLES

N1 IS RESUME/DEBUG CODE OPTION (1 = YES)

O4 IS COMPILATION LISTING OPTION (1 = YES)

OO IS PAUSE ON ERRORS OPTION (1 = YES)

P8 IS INTEGER ARITHMETIC OPTION (1 = YES)

30REM ! INTEGER QB,KV,WS,FC,C3

INTEGER VARIABLES

C3 IS COMMON KIND: -1 NONE, 0 DEFINE, 255 USE

FC IS 1 ONCE A FATAL ERROR HAS BEEN REPORTED (NO MORE CODE IS WRITTEN)

KV IS ADDRESS OF THE FIVE PACKED BYTES LEFT BY THE USR ROUTINE ($0371)

QB IS ADDRESS OF THE ROUTINE THAT READS ONE BYTE FROM THE OPEN FILE INTO IX ($037E)

WS IS ADDRESS OF THE ROUTINE THAT WRITES THE BYTE IN IX TO THE OPEN FILE ($0387)

40REM ! INTEGER VC,LB,CD,LH,DW

INTEGER VARIABLES

CD IS START OF THE COMMON BLOCK (THE PROGRAM START BEFORE COMMON MOVED IT)

DW IS DOS STATE BYTE AT $AA52: POKED BEFORE EACH DIRECT FILE READ OR WRITE

LB IS LIBRARY ADDRESS, STORED AS ADDRESS-32767

LH IS NUMBER OF SOURCE LINES READ

VC IS VARIABLES ADDRESS ASKED FOR, AS ADDRESS-32767, OR -32767 FOR END OF PROGRAM

50REM ! INTEGER HW,NG,NK,NU,MX,LQ,OH,UV,VO,LM,IX,PC,ED,CC,UR,L,KX,DP(5,1),SC(5350)

INTEGER VARIABLES

CC IS ADDRESS OF THE LINK WORD OF THE LAST DATA BLOCK (DATA BLOCKS ARE CHAINED)

ED IS OBJECT FILE BASE: FILE POSITION = PC - ED (THE FILE STARTS WITH THE BSAVE HEADER)

HW IS LAST CHAIN HEAD IN SC(); ENTRIES ARE ALLOCATED ABOVE IT

IX IS ADDRESS OF THE ONE-BYTE TRANSFER CELL FOR QB AND WS ($0376)

KX IS FIRST CONSTANT CHAIN HEAD IN SC()

L IS FIRST LINE NUMBER CHAIN HEAD IN SC()

LM IS LENGTH OF THE RUNTIME LIBRARY IN BYTES (4013)

LQ IS ADDRESS OF THE ROUTINE THAT LISTS THE TOKENIZED LINE IN THE INPUT BUFFER ($038D)

MX IS DRIVE MOTOR-ON SWITCH FOR THE BOOT SLOT ($C089+SLOT*16), TOUCHED TO KEEP THE DRIVE SPINNING

NG IS NUMBER OF CONSTANT HASH CHAINS (32)

NK IS NUMBER OF LINE NUMBER HASH CHAINS (32)

NU IS NUMBER OF VARIABLE HASH CHAINS IN THE SYMBOL TABLE (32)

OH IS INTEGER CONSTANTS OPTION (1 = YES)

PC IS ADDRESS OF THE NEXT OBJECT CODE BYTE, AS ADDRESS-32767

UR IS PROGRAM START, STORED AS ADDRESS-32767; MOVED UP BY COMMON DECLARATIONS

UV IS ADDRESS OF THE USR ROUTINE THAT PACKS A NUMBER INTO FIVE BYTES ($0377)

VO IS FIRST VARIABLE CHAIN HEAD IN SC() (9; 1-4 HOLD FN AND LINE SYMBOLS, 5-8 TEMPORARIES)
