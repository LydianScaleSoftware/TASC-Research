10 REM INTEGER VARIABLES
10 REM EL IS LIBRARY ROUTINE ($0947) THAT RESETS THE STACK, DROPPING EVERY PENDING GOSUB AND FOR, AND RESETS THE DATA POINTER; CALLED AFTER AN ERROR
10 REM MN IS DRIVE MOTOR-OFF SWITCH FOR THE BOOT SLOT
10 REM SC IS 1 IF THE SOURCE AND OBJECT FILES ARE ON THE BOOT DRIVE (MOTOR KEPT ON), ELSE 0
10 REM SC() IS SYMBOL TABLE: CHAIN HEADS, THEN ENTRIES LINKED THROUGH THEIR FIRST WORD
20 REM INTEGER VARIABLES
20 REM N1 IS RESUME/DEBUG CODE OPTION (1 = YES)
20 REM OO IS PAUSE ON ERRORS OPTION (1 = YES)
20 REM OT IS COMPILATION LISTING OPTION (1 = YES)
20 REM P8 IS INTEGER ARITHMETIC OPTION (1 = YES)
30 REM INTEGER VARIABLES
30 REM C3 IS COMMON KIND: -1 NONE, 0 DEFINE, 255 USE
30 REM CB IS START OF THE COMMON BLOCK (THE PROGRAM START BEFORE COMMON MOVED IT)
30 REM FA IS OBJECT FILE BASE: FILE POSITION = PC - FA (THE FILE STARTS WITH THE BSAVE HEADER)
30 REM FC IS 1 ONCE A FATAL ERROR HAS BEEN REPORTED (NO MORE CODE IS WRITTEN)
30 REM IX IS ADDRESS OF THE ONE-BYTE TRANSFER CELL FOR QB AND WS ($0376)
30 REM KV IS ADDRESS OF THE FIVE PACKED BYTES LEFT BY THE USR ROUTINE ($0371)
30 REM LB IS LIBRARY ADDRESS, STORED AS ADDRESS-32767
30 REM LF IS NUMBER OF SOURCE LINES READ
30 REM PC IS ADDRESS OF THE NEXT OBJECT CODE BYTE, AS ADDRESS-32767
30 REM QB IS ADDRESS OF THE ROUTINE THAT READS ONE BYTE FROM THE OPEN FILE INTO IX ($037E)
30 REM WS IS ADDRESS OF THE ROUTINE THAT WRITES THE BYTE IN IX TO THE OPEN FILE ($0387)
40 REM INTEGER VARIABLES
40 REM CA IS ADDRESS OF THE LINK WORD OF THE LAST DATA BLOCK (DATA BLOCKS ARE CHAINED)
40 REM DP() IS DOS PATCH TABLE: DP(I,0) ADDRESS (AS ADDRESS-32767), DP(I,1) ORIGINAL BYTE
40 REM DW IS DOS STATE BYTE AT $AA52: POKED BEFORE EACH DIRECT FILE READ OR WRITE
40 REM HV IS LAST CHAIN HEAD IN SC(); ENTRIES ARE ALLOCATED ABOVE IT
40 REM KX IS FIRST CONSTANT CHAIN HEAD IN SC()
40 REM L IS FIRST LINE NUMBER CHAIN HEAD IN SC()
40 REM LL IS LENGTH OF THE RUNTIME LIBRARY IN BYTES (4013)
40 REM LQ IS ADDRESS OF THE ROUTINE THAT LISTS THE TOKENIZED LINE IN THE INPUT BUFFER ($038D)
40 REM MX IS DRIVE MOTOR-ON SWITCH FOR THE BOOT SLOT ($C089+SLOT*16), TOUCHED TO KEEP THE DRIVE SPINNING
40 REM NF IS NUMBER OF CONSTANT HASH CHAINS (32)
40 REM NK IS NUMBER OF LINE NUMBER HASH CHAINS (32)
40 REM NU IS NUMBER OF VARIABLE HASH CHAINS IN THE SYMBOL TABLE (32)
40 REM OH IS INTEGER CONSTANTS OPTION (1 = YES)
40 REM PA IS PROGRAM START, STORED AS ADDRESS-32767; MOVED UP BY COMMON DECLARATIONS
40 REM UV IS ADDRESS OF THE USR ROUTINE THAT PACKS A NUMBER INTO FIVE BYTES ($0377)
40 REM VB IS VARIABLES ADDRESS ASKED FOR, AS ADDRESS-32767, OR -32767 FOR END OF PROGRAM
40 REM VN IS FIRST VARIABLE CHAIN HEAD IN SC() (9; 1-4 HOLD FN AND LINE SYMBOLS, 5-8 TEMPORARIES)
50 REM COMMON BLOCK, IN THE ORDER IT IS LAID OUT: NUMBERS FIRST, THEN STRINGS. THE PASSES SHARE IT, SO EVERY PASS DECLARES IT THE SAME WAY
50 REM BG$ IS TWO BELLS, SOUNDED BEFORE EACH ERROR MESSAGE
50 REM CL$ IS DOS CLOSE COMMAND
50 REM D$ IS CONTROL-D, THE DOS COMMAND PREFIX
50 REM DO$ IS SLOT AND DRIVE OF THE BOOT DRIVE (",S6,D1")
50 REM LF$ IS NAME OF THE LINE NUMBER FILE ("CLINENUM")
50 REM OS$ IS SLOT AND DRIVE OF THE OBJECT FILE
50 REM OT$ IS DOS OPEN COMMAND
50 REM OX$ IS OBJECT FILE NAME
50 REM RO$ IS DOS READ COMMAND
50 REM SE$ IS SLOT AND DRIVE OF THE SOURCE FILE
50 REM SI$ IS SOURCE FILE NAME
50 REM WF$ IS DOS WRITE COMMAND
