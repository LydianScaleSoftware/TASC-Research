10 REM INTEGER VARIABLES
10 REM EL IS LIBRARY ROUTINE ($0947) THAT RESETS THE STACK, DROPPING EVERY PENDING GOSUB AND FOR, AND RESETS THE DATA POINTER; CALLED AFTER AN ERROR
10 REM MN IS DRIVE MOTOR-OFF SWITCH FOR THE BOOT SLOT
10 REM SC IS 1 IF THE SOURCE AND OBJECT FILES ARE ON THE BOOT DRIVE (MOTOR KEPT ON), ELSE 0
20 REM INTEGER VARIABLES
20 REM N1 IS RESUME/DEBUG CODE OPTION (1 = YES)
20 REM O4 IS COMPILATION LISTING OPTION (1 = YES)
20 REM OO IS PAUSE ON ERRORS OPTION (1 = YES)
20 REM P8 IS INTEGER ARITHMETIC OPTION (1 = YES)
30 REM INTEGER VARIABLES
30 REM C3 IS COMMON KIND: -1 NONE, 0 DEFINE, 255 USE
30 REM CC IS START OF THE COMMON BLOCK (THE PROGRAM START BEFORE COMMON MOVED IT)
30 REM FC IS 1 ONCE A FATAL ERROR HAS BEEN REPORTED (NO MORE CODE IS WRITTEN)
30 REM KV IS ADDRESS OF THE FIVE PACKED BYTES LEFT BY THE USR ROUTINE ($0371)
30 REM LB IS LIBRARY ADDRESS, STORED AS ADDRESS-32767
30 REM QB IS ADDRESS OF THE ROUTINE THAT READS ONE BYTE FROM THE OPEN FILE INTO IX ($037E)
30 REM WS IS ADDRESS OF THE ROUTINE THAT WRITES THE BYTE IN IX TO THE OPEN FILE ($0387)
40 REM INTEGER VARIABLES
40 REM ED IS OBJECT FILE BASE: FILE POSITION = PC - ED (THE FILE STARTS WITH THE BSAVE HEADER)
40 REM IX IS ADDRESS OF THE ONE-BYTE TRANSFER CELL FOR QB AND WS ($0376)
40 REM LG IS NUMBER OF SOURCE LINES READ
40 REM PC IS ADDRESS OF THE NEXT OBJECT CODE BYTE, AS ADDRESS-32767
50 REM INTEGER VARIABLES
50 REM HV IS LAST CHAIN HEAD IN SE(); ENTRIES ARE ALLOCATED ABOVE IT
50 REM KX IS FIRST CONSTANT CHAIN HEAD IN SE()
50 REM MX IS DRIVE MOTOR-ON SWITCH FOR THE BOOT SLOT ($C089+SLOT*16), TOUCHED TO KEEP THE DRIVE SPINNING
50 REM NF IS NUMBER OF CONSTANT HASH CHAINS (32)
50 REM NU IS NUMBER OF VARIABLE HASH CHAINS IN THE SYMBOL TABLE (32)
60 REM INTEGER VARIABLES
60 REM CB IS ADDRESS OF THE LINK WORD OF THE LAST DATA BLOCK (DATA BLOCKS ARE CHAINED)
60 REM DW IS DOS STATE BYTE AT $AA52: POKED BEFORE EACH DIRECT FILE READ OR WRITE
60 REM L IS FIRST LINE NUMBER CHAIN HEAD IN SE()
60 REM LL IS LENGTH OF THE RUNTIME LIBRARY IN BYTES (4013)
60 REM LQ IS ADDRESS OF THE ROUTINE THAT LISTS THE TOKENIZED LINE IN THE INPUT BUFFER ($038D)
60 REM MJ IS PROGRAM START, STORED AS ADDRESS-32767; MOVED UP BY COMMON DECLARATIONS
60 REM NK IS NUMBER OF LINE NUMBER HASH CHAINS (32)
60 REM OH IS INTEGER CONSTANTS OPTION (1 = YES)
60 REM SE() IS SYMBOL TABLE: CHAIN HEADS, THEN ENTRIES LINKED THROUGH THEIR FIRST WORD
60 REM UE IS VARIABLES ADDRESS ASKED FOR, AS ADDRESS-32767, OR -32767 FOR END OF PROGRAM
60 REM UV IS ADDRESS OF THE USR ROUTINE THAT PACKS A NUMBER INTO FIVE BYTES ($0377)
60 REM VN IS FIRST VARIABLE CHAIN HEAD IN SE() (9; 1-4 HOLD FN AND LINE SYMBOLS, 5-8 TEMPORARIES)
70 REM INTEGER VARIABLES
70 REM DP() IS DOS PATCH TABLE: DP(I,0) ADDRESS (AS A SIGNED WORD, ADDRESS-65536), DP(I,1) ORIGINAL BYTE
80 REM COMMON BLOCK, IN THE ORDER IT IS LAID OUT: NUMBERS FIRST, THEN STRINGS. THE PASSES SHARE IT, SO EVERY PASS DECLARES IT THE SAME WAY
80 REM BG$ IS TWO BELLS, SOUNDED BEFORE EACH ERROR MESSAGE
80 REM CG$ IS DOS CLOSE COMMAND
80 REM D$ IS CONTROL-D, THE DOS COMMAND PREFIX
80 REM DF$ IS SLOT AND DRIVE OF THE BOOT DRIVE (",S6,D1")
80 REM LE$ IS NAME OF THE LINE NUMBER FILE ("CLINENUM")
80 REM OO$ IS SLOT AND DRIVE OF THE OBJECT FILE
80 REM OP$ IS DOS OPEN COMMAND
80 REM OY$ IS OBJECT FILE NAME
80 REM RP$ IS DOS READ COMMAND
80 REM SI$ IS SOURCE FILE NAME
80 REM SY$ IS SLOT AND DRIVE OF THE SOURCE FILE
80 REM WE$ IS DOS WRITE COMMAND
